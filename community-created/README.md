These are notebooks contributed by the PUNCH community.

**visualization**: two notebooks for the Radial Histogram Equalizing Filter (RHEF),
which flattens the corona's steep radial brightness falloff so faint outer structure
reads as clearly as the bright inner corona. Start with `rhef_punch_beginner.ipynb`,
which assumes no Python or Jupyter experience and ends with one figure;
`rhef_punch_videos.ipynb` goes further with many frames, the `upsilon` knob and an
MP4. Both pull PUNCH level-3 CAM mosaics from the public archive and need Python 3.12
or newer. Contributed by Gilly (NWRA); the method is described in Gilly & Cranmer
2025, Solar Physics, [doi:10.1007/s11207-025-02578-x](https://doi.org/10.1007/s11207-025-02578-x).
